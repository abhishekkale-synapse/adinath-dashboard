Global Session Architecture Plan

Telemetry Standardization: Unifying Eye Tracking, Touch, and Lexi under a Single Root Session

Executive Summary

Currently, BankAbility operates with three isolated session identifiers: Eye Tracking uses a database UUID, Touch generates per-screen text timestamps (session-Date.now()), and Lexi generates a separate conversation_id. This architecture plan establishes the Global App Session Pattern to unify all telemetry under a single standard UUID.

Architecture Comparison

Current Fragmented State High Technical Debt

  • Touch: Generates text strings session-${Date.now()} on every screen mount.
  • Eye Tracking: Generates a strict database UUID.
  • Lexi Chat: Generates an independent conversation_id.
  • Database Impact: Schema format mismatch requires dedicated tables or duplicate columns.
  • AI Impact: Cannot join simultaneous eye jitter, touch errors, and user chat choices together in real time.

Future Global State Industry Standard

  • Single Root Session: App generates one standard UUIDv4 or UUIDv7 at launch.
  • Zero DB Migration: All Postgres tables (user_actions, messages, touch_cognitive_scores) natively support 36-char UUIDs.
  • Lifecycle: 30-minute standard inactivity auto-rotation.
  • Full Multimodal AI: Allows single-query correlation: WHERE session_id = 'xyz'.

System Architecture Flow

Target Telemetry Pipeline (Single Root UUID Envelope)
Mobile App Launch → AppSessionProvider (UUIDv4) → Global session_id: "550e8400-e29b-..."
1. Eye Tracking Recorder → eye_tracking_sessions table (session_id)
2. Touch / Keystrokes (useActionTracker) → user_actions / touch_cognitive_scores (session_id)
3. Lexi Chat (WebSocket Gateway) → conversations / messages table (conversation_id)

Industry Standard References & Standards

🔗 Segment (Twilio) Common Analytics Spec - Sessions
Industry specification for session tracking, showing how mobile and web telemetry propagate a unified sessionId across all interaction events.
🔗 PostHog - Session Tracking & ID Lifecycle
Standard production guidelines for session rotation, inactivity timeouts (30 minutes), and cross-component correlation.
🔗 W3C Trace Context Specification
International standard for distributed telemetry correlation, defining how parent context envelopes group disparate subsystem signals.
🔗 IETF RFC 9562: UUID Standard (UUIDv4 & UUIDv7)
The official internet engineering standard defining Universally Unique Identifiers for distributed systems and database indexing.
